# 题库制作规范（schema 3）

题包是 UTF-8 JSON 对象，放在 `data/packs/`，并在 `data/manifest.json` 的 `packs` 数组中登记。正式题库使用 `schemaVersion: 3`。

## 顶层字段

必须包含 `schemaVersion`、`id`、`version`、`title`、`locales`、`categories` 和 `questions`。语言固定为 `en`、`zh-Hans`、`zh-Hant`。ID 只能使用 ASCII 字母、数字、点、下划线和连字符。

## 题目字段

每道原题只保存一次。`difficulty` 为 1–4；选择题自动对应 100/200/300/400 分，简答题使用 `openPoints`，必须分别为 200/400/600/800。

```json
{
  "id": "science-001",
  "categoryId": "science",
  "difficulty": 1,
  "formats": ["choice", "open"],
  "openPoints": 200,
  "options": ["a", "b", "c", "d"],
  "correctOptionId": "a",
  "locales": {
    "en": {
      "prompt": "Question text",
      "openPrompt": "Short-answer question text",
      "optionLabels": {"a":"A","b":"B","c":"C","d":"D"},
      "answer": "Reference answer",
      "acceptedAnswers": ["Reference answer"],
      "rubric": "Accept an unambiguous equivalent answer."
    },
    "zh-Hans": {"prompt":"题干","optionLabels":{"a":"选项A","b":"选项B","c":"选项C","d":"选项D"},"answer":"参考答案"},
    "zh-Hant": {"prompt":"題幹","optionLabels":{"a":"選項A","b":"選項B","c":"選項C","d":"選項D"},"answer":"參考答案"}
  }
}
```

包含 `open` 的 schema 3 题目必须填写 `openPoints = difficulty × 200`。`acceptedAnswers` 和 `rubric` 如果出现，必须是有效文本。`formats` 可以省略，默认同时支持两种形式；也可以明确写 `choice` 或 `open`。选择题需要 3–6 个稳定的 `options` 和一个 `correctOptionId`。简答题需要三语 `answer`；可用 `openPrompt` 改写简答题题干。

题库中的来源、许可、审阅记录等字段可以作为附加元数据保留，但游戏判分只使用上述规范字段。玩家记录、隐藏状态和答题历史不能写回题库。

## 校验与生成

```bash
python tools/build.py --validate-only
python tools/build.py
```

第二条命令会生成 `data/builtin.js`。修改题目、翻译、答案或分值后必须更新题包 `version`；内容指纹变化会使旧存档要求匹配的旧题包。

schema 2 仍可用于读取旧题包，但旧题包的简答题保持旧的 500/600/700/800 分规则；schema 2 不允许加入 `openPoints`。新题库请使用 schema 3。
